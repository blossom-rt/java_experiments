## 当前状态

### 功能特性

- 4×4 棋盘，标准 2048 玩法
- 方向键（↑ ↓ ← →）控制方块移动与合并
- 右上角「重新开始」按钮，鼠标点击即可重开；也可随时按 `R` 重开
- 顶部实时显示当前分数
- 合成 2048 方块触发通关提示，此局暂时定格，按 `C` 可继续挑战更高分
- 无空格且无相邻可合并方块时游戏结束
- 仿原版 2048 的方块配色（2 ~ 8192）
- 游戏结束 / 通关时在棋盘区显示半透明遮罩，分数栏与按钮保持清晰可见

### 实现说明

项目为单文件实现（`Game2048.java`），核心设计如下：

- **数据结构**：使用 `int[SIZE][SIZE]` 二维数组存储棋盘状态，`0` 表示空格；`SIZE = 4` 定义棋盘边长，窗口与棋盘尺寸都由它和方块尺寸常量推导。
- **移动与合并**：`slideRow()` 是纯函数——对单行先压缩（去除空格 0）、再对相邻相同数字合并（每个方块每步只合并一次）、最后再次压缩，返回「是否发生移动」与本行得分，不修改任何全局状态；由 `move()` 汇总分数。
- **四个方向**：通过 `rotate()` 将棋盘整体顺时针旋转，把上、下、右三个方向统一转换为"向左移动"，四个方向共用同一套合并逻辑。
- **随机方块**：`addRandomTile()` 在剩余空格中等概率生成 2 或 4（各 50%，比原版更硬核）。
- **通关与结束**：`hasTile(2048)` 判定是否出现 2048 方块，只在首次达成时弹一次通关提示，`won` 标记保证继续游戏后不会重复触发；`isGameOver()` 检查棋盘无空格且任意相邻格子均不相等时判定游戏结束。
- **界面渲染**：内部类 `GamePanel` 继承 `JPanel`，重写 `paintComponent()` 完成绘制，开启图形与文字抗锯齿；「重新开始」按钮为自绘圆角按钮，带悬停 / 按下反馈。
- **字体适配**：运行时探测系统中可用的中文字体（微软雅黑 → 黑体 → 逻辑字体），避免字体名硬编码在别的系统上显示为方块。
- **键盘交互**：方向键与 `R` / `C` 绑定在根面板的 `InputMap` / `ActionMap` 上（`WHEN_IN_FOCUSED_WINDOW`），因此点击按钮、切换焦点之后方向键依然有效。

### 运行方式

需要 JDK 8 及以上版本。

```bash
# 编译（源码含中文，必须指定 UTF-8 编码，否则中文 Windows 的默认 GBK 会把中文编乱）
javac -encoding UTF-8 Game2048.java

# 运行
java Game2048
```

## 后续改进

以下是后续可考虑的改进方向，按类别整理：

### 游戏机制

- **撤销上一步（Undo）**：记录每步移动前的棋盘状态，按 `Z` 或点击按钮回退一步，方便失误时挽救。
- **最高分记录**：将历史最高分持久化到本地文件，重启程序后仍能查看。
- **难度设置**：目前新方块按 50% / 50% 生成 2 或 4，可提供难度选项（简单 / 标准 / 困难），或把生成概率做成可配置项。

### 交互与界面

- **鼠标拖拽**：支持用鼠标拖拽方块移动，弥补纯键盘操作在上手成本上的不足。
- **移动动画**：为方块滑动、合并、新方块生成添加平滑动画，让操作反馈更直观。
- **音效**：合并、通关、失败时播放提示音，增强游戏沉浸感。
- **界面主题**：支持浅色 / 深色主题切换，或提供多套配色方案。

### AI 辅助

- **提示功能**：按 `H` 键显示 AI 计算出的最佳下一步方向，帮助新手学习策略。
- **自动演示**：按 `A` 键让 AI 自动玩一局，直观展示高分局是怎么打出来的。

### 工程化

- **多文件重构**：将单文件拆分出棋盘逻辑、渲染、入口等模块，便于维护与扩展。
- **单元测试**：引入 JUnit，为移动 / 合并 / 结束判定等核心逻辑编写自动化测试（`slideRow()` 已是纯函数，可直接喂数组断言）。
- **构建工具**：接入 Maven / Gradle 管理依赖与构建流程，替代直接 `javac` 编译。
